# Sahil Aslam - 3D Portfolio

Welcome to my interactive 3D portfolio! This is where you'll find my projects, skills, and everything I've been working on.

## What's This About?

I built this portfolio to showcase my work as a full-stack developer. Instead of a boring static page, I wanted to make something that feels modern and interactive. It's all 3D, smooth animations, and designed to give you a real sense of what I can do.

## What's Inside

- **Interactive 3D Experience** – The whole site is built with 3D graphics, so it's not your typical portfolio
- **Project Showcase** – Check out what I've worked on
- **Skills & Experience** – Everything from the tech stack I use to my background
- **Contact** – Reach out directly through the site

## Tech Stack

Here's what powers this thing:

- **React** – Building the UI
- **Three.js & React Three Fiber** – All the 3D magic
- **Framer Motion** – Smooth animations everywhere
- **Tailwind CSS** – Styling that actually works
- **Vite** – Super fast dev environment
- **EmailJS** – Contact form handling

And a few other tools like react-router for navigation and react-parallax-tilt for some nice tilt effects.

## Getting Started

Want to run this locally? Here's how:

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repo:
```bash
git clone https://github.com/sahilaslam-art/sahilaslam-portfolio.git
cd sahilaslam-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the dev server:
```bash
npm run dev
```

The site will be running at `http://localhost:5173` (or whatever port Vite assigns).

## Building for Production

Ready to deploy? Just run:

```bash
npm run build
```

This creates an optimized version in the `dist` folder that you can throw on any hosting service.

To preview the production build locally:
```bash
npm run preview
```

## Project Structure

- `src/` – All the React components and logic
- `src/components/` – Reusable components for different sections
- `src/constants/` – Fixed data like skills and experience
- `src/hoc/` – Higher-order components (wrapper stuff)
- `public/` – Static assets like images and SVGs
- `assets/` – Additional media files

## Customization

Want to use this as a template for your own portfolio? No problem:

- Update the content in `src/constants/` with your own info
- Replace the images in `public/` and `assets/`
- Tweak the colors and styles in `tailwind.config.js`
- Modify components to match your vibe
